# Kursregeln 259.075

Gilt für alle sieben Einheiten. Die einzelnen Pläne verweisen hierher, statt es jedes Mal zu
wiederholen.

## Keine Ausreden, in beide Richtungen

Der Satz, den niemand sagen können soll, lautet: "Mein Code ist nicht gelaufen, deshalb habe
ich nichts abgegeben." Dagegen ist der Kurs gebaut, und zwar so, dass daraus keine bequeme
Tür wird.

**In der Stunde.** Jede Lückenaufgabe hat eine Auflösung, und die wird nach zehn Minuten
freigeschaltet, nicht erst am Ende. Wer festhängt, holt sie sich, liest sie, macht weiter.
Das kostet keinen Punkt, weil die Punkte woanders liegen. Wer sie nimmt, arbeitet danach an
derselben Aufgabe weiter wie alle anderen, nur eben mit fremdem Code als Startpunkt.

**Bei der Hausübung.** Die Lösung der Codezeilen steht nach der Einheit im Lösungsnotebook.
Damit ist der Code nie der Grund für eine fehlende Abgabe. Abgegeben wird ein eigener Lauf
mit eigenen Zahlen und die eigene Deutung dazu, und wer die Musterzeilen verwendet hat,
schreibt das in einer Zeile dazu. Das ist keine Schande und kostet nichts.

**Was sehr wohl zählt.** Ohne Abgabe gibt es null Punkte, und der Deutungsteil wird streng
bewertet. Wer schreibt, was er gesehen hat, und begründet, was es bedeutet, bekommt die
Punkte auch mit geliehenem Code. Wer fünf allgemeine Sätze hinschreibt, die auf jedes Modell
passen würden, bekommt sie nicht.

**Wer nach zehn Minuten noch nicht läuft**, arbeitet zu zweit an einem Rechner weiter. Nicht
zuschauen, mitschreiben.

## Warum das so ist

Der Kurs prüft, ob jemand ein Modell beurteilen kann, nicht ob er Python tippen kann. Die
Programmierung ist Werkzeug, und ein Werkzeug darf man sich reichen lassen. Das Urteil nicht.
